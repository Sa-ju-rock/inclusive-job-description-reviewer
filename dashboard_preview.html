SDG 5 Guide

Best Practices for Gender-Neutral Job Descriptions

1. Focus on Outcomes, Not Traits

Instead of asking for "aggressive leaders", specify deliverables like "deliver REST API endpoints and scale data pipelines".

2. Remove Superhero Tropes

Phrases like "ninja", "rockstar", and "code wizard" signal an exclusionary culture and alienate diverse technical talent.

3. Separate Must-Have vs Nice-to-Have

Research shows men apply when meeting ~60% of requirements, while women apply only when meeting 100%. Keep core requirements concise.
